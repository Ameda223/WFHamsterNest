# WFHamsterNest · Warframe 小仓鼠

> 一个为 Warframe 玩家打造的桌面辅助工具。

---

## 📖 项目简介

**b本程序是一个面向《Warframe》玩家的桌面助手程序。它不会修改游戏文件、不注入进程，只通过外部识别与查询，为你提供以下实用功能：

- 🔍 开遗物自动识别并查询 Prime 部件价格
- 📈 Prime 物品 & 紫卡市场价格走势
- 🌌 裂缝监控与桌面刷新提醒
- 🌐 AI 大模型实时翻译，与老外交易沟通无障碍
- 🎮 手柄宏功能，简化重复操作(自用, xbox/ds5手柄搞个拍手都费劲, steam自带的不好用,其它程序收费所以自己搞了个简单的)

---

## ✨ 功能特性

### 1. 开遗物自动识别 & Prime 价格查询
开启遗物后，按下快捷键程序会自动识别屏幕上的遗物奖励，并实时查询对应 Prime 部件的市场价格。不用再手动切网页、输入名字，一眼就知道该选哪个。

### 2. 市场 Prime 物品 & 紫卡价格走势
- 查看 Prime 套件、单件、紫卡的历史价格走势
- 支持按时间范围查看涨跌
- 数据来源为公开市场 API

### 3. 裂缝监控 & 桌面提醒
- 实时监控虚空裂缝任务刷新
- 新裂缝出现时弹出桌面通知，不错过任何一次开遗物机会
- 可按任务类型、裂隙等级筛选提醒

### 4. AI 翻译
- 接入大语言模型，实时翻译聊天窗口内容(需要手动截屏识别)
- 与国外玩家交易时，再也不用复制粘贴到翻译软件
- 翻译结果直接发送到助手弹窗中,输入中文时自动翻译为英文(可开启自动发送到游戏中)


### 5. 手柄宏功能
- 支持自定义手柄按键宏，简化重复操作
- 所有宏均在系统层面模拟输入，不修改游戏内存

## ❓ 常见问题

**Q：程序会修改游戏文件吗？会被封号吗？**  
A：不会修改任何游戏文件，也不注入进程。所有功能均基于屏幕识别、外部 API 查询和系统级输入模拟。但请注意，使用任何第三方辅助工具都存在一定风险，请自行权衡。

**Q：为什么仓库里没有源代码？**  
A：本仓库主要用于分发更新数据与清单，程序主体通过 Releases 发布。源代码暂未公开。

**Q：数据更新失败怎么办？**  (你能打开这里,估计不会出现更新失败的问题)
A：请检查网络连接，或尝试使用代理。如果持续失败，可在 Issues 中反馈。

**Q：程序为何需要管理员权限运行？**
A：由于加入了系统按键模拟输入的功能,只能在管理员权限下使用
